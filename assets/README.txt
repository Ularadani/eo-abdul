CARA PASANG FOTO
================
Taruh foto di folder assets/images/ dengan nama persis seperti di bawah.
Tidak perlu mengubah kode. Kalau foto belum ada, website otomatis
memakai warna gradien sebagai gantinya.

Nama file            Dipakai di                     Ukuran saran
-------------------  -----------------------------  ---------------
hero.jpg             Latar halaman Beranda          1920 x 1080 px
porto-1.jpg          Portofolio: Pernikahan Rina    1200 x 900 px
porto-2.jpg          Portofolio: Gathering PT Nusa  1200 x 900 px
porto-3.jpg          Portofolio: Festival Musik     1200 x 900 px
porto-4.jpg          Portofolio: Wisuda             1200 x 900 px
porto-5.jpg          Portofolio: Garden Wedding     1200 x 900 px
porto-6.jpg          Portofolio: Peluncuran Produk  1200 x 900 px
favicon.svg          Ikon di tab browser            (sudah ada)

Aturan:
- Format harus .jpg (huruf kecil semua). Foto .png ubah dulu jadi .jpg.
- Usahakan tiap foto di bawah 500 KB supaya website cepat dibuka.
- Foto portofolio pakai orientasi mendatar (landscape).
- Nama acara di tiap foto diganti lewat file index.html, cari "abdul_porto".

CARA PASANG VIDEO
=================
Taruh video di folder assets/video/ dengan nama persis seperti di bawah.
Kalau video belum ada, bagian video otomatis disembunyikan.

Nama file     Dipakai di                              Saran
-----------   --------------------------------------  ---------------------
hero.mp4      Latar Beranda, jalan otomatis tanpa     Durasi 10-20 detik,
              suara dan berulang                      1280 x 720, maks 8 MB
profil.mp4    Video profil di bagian Tentang,         Durasi bebas, 1280 x 720,
              ada tombol play dan suara               maks 30 MB

Aturan:
- Format harus .mp4 (kode video H.264) dengan huruf kecil semua.
- Video latar (hero.mp4) sebaiknya tanpa dialog karena diputar tanpa suara.
- Kalau ukuran terlalu besar, kecilkan dulu lewat HandBrake atau layanan kompres video.
